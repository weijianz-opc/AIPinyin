AllInOneIME 安装说明

1. 双击「安装 AllInOneIME」，点「安装」。
   输入法装到 ~/Library/Input Methods，「AllInOneIME 设置」装到 ~/Applications，
   并加进你的输入法列表。只装给当前用户，不需要管理员密码。
2. 如果 macOS 说无法验证「安装 AllInOneIME」、没有打开它：点「完成」（macOS 14 上是「取消」），
   打开 系统设置 → 隐私与安全性，在页面下方找到关于「安装 AllInOneIME」的提示，
   点「仍要打开」并按提示确认（可能要输入密码）。安装包还没有经过 Apple 公证，
   macOS 验证不了它是谁做的：只用从 GitHub Releases 下载的安装包。
3. 装好后用 Ctrl+空格 切换到 AllInOneIME。要用 @improve 和 @question，
   先在「AllInOneIME 设置」里配置 Amazon Bedrock（用你自己的 AWS 账号）。

更新：用新版的磁盘映像再安装一次，不用先卸载。
卸载：打开「安装 AllInOneIME」，点「卸载…」。设置和学到的词会保留。
需要 macOS 14 或更新版本；语音输入需要 macOS 26 或更新版本。
使用说明：https://github.com/weijianz-opc/AllInOneIME/wiki


Installing AllInOneIME

1. Double-click "Install AllInOneIME" and click Install.
   The input method goes into ~/Library/Input Methods and "AllInOneIME Settings" into
   ~/Applications, and it's added to your input sources. For this user only; no administrator
   password needed.
2. If macOS says it can't verify "Install AllInOneIME" and doesn't open it: click Done (Cancel on
   macOS 14), open System Settings → Privacy & Security, find the message about "Install
   AllInOneIME" near the bottom, click Open Anyway and confirm (it may ask for your password).
   The installer isn't notarized by Apple yet, so macOS can't verify who made it: only use one
   downloaded from GitHub Releases.
3. Then switch to AllInOneIME with Ctrl+Space. For @improve and @question, set up Amazon Bedrock
   (your own AWS account) in AllInOneIME Settings first.

To update: install again from the new disk image; there's no need to uninstall first.
To uninstall: open "Install AllInOneIME" and click Uninstall…. Settings and learned words are kept.
Needs macOS 14 or later; voice input needs macOS 26 or later.
Documentation: https://github.com/weijianz-opc/AllInOneIME/wiki
